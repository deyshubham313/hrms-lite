# 🚀 Ethara.AI - HRMS Lite

**Ethara.AI HRMS Lite** is a futuristic, lightweight Human Resource Management System designed to streamline employee data management and attendance tracking. Built with a focus on modern UI/UX, it features a "Cyber/High-Tech" aesthetic with real-time visualizations, glassmorphism design, and interactive data dashboards.

## 🌟 Project Overview

This Full-Stack application allows HR administrators to:
* **Manage Personnel:** Onboard new employees ("Units") and manage the active roster with a secure database.
* **Track Operations:** Log daily attendance status (Active/Inactive) and visualize operational uptime.
* **Visualize Data:** View real-time metrics on department distribution and workforce status using interactive charts.
* **Immersive UI:** Experience a cinematic "System Boot" intro, custom neon cursors, and animated page transitions.

## 🛠️ Tech Stack

* **Frontend:** [Streamlit](https://streamlit.io/) (Python)
* **Backend:** [FastAPI](https://fastapi.tiangolo.com/) (Python)
* **Visualization:** Plotly Express
* **Animations:** Lottie Files (via `streamlit-lottie`) & CSS Animations
* **Styling:** Custom CSS (Glassmorphism, Neon Glow effects)
* **Deployment:** Render (Backend) & Streamlit Cloud (Frontend)
